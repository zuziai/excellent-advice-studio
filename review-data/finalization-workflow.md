# Final selections and reusable prompts

User requirement recorded on 2026-10-10, with column order revised on 2026-10-19: every explicitly selected final image must be saved as the original full-quality image, downloaded in the review browser, and accompanied by a complete English generation prompt in column D of the original workbook on the sentence's own row.

- Workbook: `Excellent-Advice-460-FA.xlsx`, sheet `ترجمه‌ها`. A is sentence ID, B is the original English sentence, C is `ترجمه‌ی فارسی`, D is `پرامپت کامل انگلیسی تصویر`. All 460 original translations and existing prompts are preserved. Find the row by its ID; do not assume the sentence number is the Excel row number.
- Before publishing any new candidate or edited version, save a standalone English prompt that describes the actual final composition, all story panels, cast, actions, expressions, watercolor and character style, necessary Persian text, and constraints. Persian inside this English prompt is limited to the exact text to be drawn in the image. A short edit request or “keep the attached image” is insufficient. Keep the original generation/edit prompt and reference provenance separately.
- Candidate metadata fields: `fullGenerationPromptEnglish`, `fullGenerationPromptEnglishPath`, `fullGenerationPromptEnglishHash`. Bind them to the candidate ID and its original PNG hash. Existing candidates in this review wave receive the same fields before selection.
- Save only the current explicit `approved` choice for the current wave. Pending edits, rejected ideas, old approvals in feedback history, and images awaiting review are not final selections. A completed edit becomes pending review and needs its own approval.
- Local server `book-review/server.py` first preserves feedback, then invokes `book-review/finalization.py`. The finalizer calls `review-data/save-approved-prompts.mjs` to author and verify the workbook with the bundled spreadsheet runtime, then saves original PNG bytes as `Images/{sentenceId}.png`. Replacing an earlier final selection preserves a hash-verified backup and approval history.
- The workbook cell contains the entire prompt with paragraph whitespace compacted for display; readable full prompts are also kept as UTF-8 text files. Track the source prompt hash and the stored cell hash separately. Do not claim that a generation prompt guarantees identical pixels on a later generation.
- A finalization is complete only after both original image bytes and workbook prompt are verified. The UI shows progress and a retry control for incomplete finalization. An open/locked workbook must not produce a false success notice or lose the review decision.
- A fresh successful final approval triggers one native browser download of that exact candidate's original PNG. Reopening the page must not download again. The ordinary download control always refers to the currently displayed image version.
- `book-review/finish_review.py --apply-approved` resumes current approved choices if the user exported feedback before the automatic flow was installed. Repeating a successful finalization is idempotent and does not duplicate approval history or image files.
- Read the revised workbook using header names: the Persian translation is now C and the full English image prompt is D. `review-data/extract-book-data.py` supports both the original and revised column layout.
